## 2. How to Import Your Rendered Google Flow Videos

Once you render the 3 `.mp4` videos in Google Flow:
1. Drop them into `C:\learning\websites\aurum-biomimetic-dental\assets\raw\`:
   - `assets/raw/scene-01-hero.mp4`
   - `assets/raw/scene-02-implant.mp4`
   - `assets/raw/scene-03-scan-whitening.mp4`
2. Run the automated frame & binary-pack compiler:
   ```bash
   npm run frames
   ```
   This runs `python tools/extract_flow_videos.py`, which:
   - Extracts `180` high-sharpness `1920×1080` Desktop WebP frames (`q=86`) into `public/frames/<scene>/desktop/frame_%04d.webp` + `poster-desktop.webp`.
   - Extracts `144` `854×480` Mobile WebP frames and packs them into `public/frames/<scene>/mobile-pack-v3.bin` + `mobile-pack-v3.json` + `poster-mobile-v3.webp` for 60/120fps `ReadableStream` scrubbing on iOS/Android.
